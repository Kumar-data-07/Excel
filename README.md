# 📊 UPI Transactions Analytics Dashboard – Excel

## 📌 Project Overview

The **UPI Transactions Analytics Dashboard** is an interactive data analytics project developed using **Microsoft Excel** to analyze UPI transaction performance across multiple dimensions.

The dashboard provides a consolidated view of transaction volume, transaction value, success rate, cashback, suspected fraud, UPI applications, banks, states, transaction types, merchants, and transaction timing.

The project demonstrates how Excel can be used to transform raw transaction data into an interactive and business-focused analytical dashboard.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall UPI transaction performance.
- Monitor total transaction volume and transaction value.
- Analyze transaction success, failure, pending, and refund rates.
- Compare transaction activity across UPI applications.
- Analyze transaction values across different states and banks.
- Identify popular transaction types.
- Analyze transaction activity by hour and day.
- Monitor suspected fraudulent transactions.
- Provide interactive filtering for detailed analysis.

## 📈 Dashboard Features

### 🔹 Transaction Overview
Provides an overall view of:

- Total transactions
- Total transaction amount
- Total cashback
- Success rate
- Suspected fraud transactions

### 🔹 UPI Application Analysis

Analyzes transaction distribution across major UPI applications:

- PhonePe
- Google Pay
- Paytm
- Amazon Pay
- BHIM
- Cred Pay
- WhatsApp Pay

### 🔹 Transaction Status Analysis

Transactions are categorized into:

- Success
- Failed
- Pending
- Refunded

The dashboard displays an overall success rate of **91.05%**.

### 🔹 State-wise Analysis

The dashboard provides geographical analysis of transaction amounts across Indian states using a map visualization.

### 🔹 Bank-wise Analysis

Transaction amounts are compared across different banks, including:

- HDFC Bank
- SBI
- Kotak Mahindra Bank
- Canara Bank
- ICICI Bank
- Axis Bank
- Bank of Baroda
- Punjab National Bank

### 🔹 Transaction Type Analysis

The project analyzes different UPI transaction types:

- P2M
- P2P
- Bill Payment
- Online Shopping
- Recharge
- Subscription
- Wallet Transfer

### 🔹 Time-based Analysis

Transaction activity is analyzed by:

- Day
- Hour
- Day & Hour combination

A heatmap is used to identify transaction activity patterns throughout the week.

### 🔹 Merchant Analysis

The dashboard allows users to explore transaction activity based on:

- Merchant Name
- Merchant Category

### 🔹 Interactive Filters

Users can dynamically filter the dashboard using:

- City
- Gender
- Merchant Category
- Merchant Name
